# TradeUp — симулятор трейдинга для Яндекс Игр

Ванильный HTML/CSS/JS без движка и сборки. Фирменный стиль «золото на графите»
по логотипу, анимации (вспышки цены, твн капитала, каскадные появления, rAF-график),
топ-200 монет с реальными ценами и локальными логотипами, алфавитная сортировка
с буквенными разделителями и поиском, 5 таймфреймов, ежедневный бонус, бонус
за рекламу (rewarded video), лидерборд, классы трейдера, темы, локализация RU/EN.
Фьючерсы: бессрочные контракты с плечом до 50×, лонг/шорт, ликвидация, фандинг, TP/SL.

> Скрипты `tools/`, упомянутые ниже, в репозиторий не добавлены.
> Для Яндекс Игр нужен предоставляемый платформой `/sdk.js`.

## Ассеты

- `img/logo.png` / `img/logo-small.png` (256×256) — фирменный логотип.
- `img/coins/{id}.png` — логотипы 200 монет (мелкие версии из CoinGecko).
- `img/icons/*.svg` — набор Tabler Icons (MIT); иконки вкладок встроены inline.
- `img/icons/class-{key}.png` (160×160, RGBA) — эмблемы классов трейдера.
  Нарезаются скриптом `python tools/split_classes.py` из сетки
  `img/icons/classes-source.jpg`: скрипт сам находит каждую эмблему
  (бинаризация → закрытие → связные компоненты), вырезает по центру
  масс и накладывает круглую маску. Порядок эмблем в сетке должен
  совпадать с порядком `CLASSES` в `js/data.js`.
  **PNG не обязательна**: подключение идёт по наличию поля `img` в
  `CLASSES`. Убрать поле — и эмблема снова рисуется inline SVG из
  `classIconHTML()` (фолбэк живёт в `js/main.js`).
- Список монет: `js/data-coins.js` — **генерируется** скриптом
  `python tools/gen_coins_200.py` (тянет топ-200 CoinGecko без стейблкоинов,
  скачивает логотипы, считает волатильность по рангу). Не редактировать вручную.
- Логотипы монет — товарные знаки соответствующих проектов; используются
  исключительно для обозначения актива внутри игры-симулятора.

## Локальный запуск

```
python -m http.server 8018
# открыть http://localhost:8018/
```

Вне Яндекса SDK работает в мок-режиме (`js/yandex-sdk.js`): сейвы в localStorage,
реклама-заглушка, язык из браузера.

Для запуска версии из GitHub: скачайте архив через **Code → Download ZIP**
(репозиторий приватный, потребуется доступ к нему), распакуйте его,
откройте терминал в папке с `index.html` и выполните команду выше.
Не открывайте `index.html` напрямую через `file://`: для локальных запросов
ресурсов нужен HTTP-сервер. Отсутствующий при локальном запуске `/sdk.js`
запрашивается браузером, но обёртка использует мок-режим.

Dev-скрипты `_dev_seed.js` и `_dev_orders.js` подключаются только на
локальном адресе с параметром `?dev=orders` (или `_dev_seed.js` при других
поддерживаемых значениях `dev`); они могут изменять локальное сохранение.
Для обычной игры открывайте страницу без `?dev=`.

Для открытия по публичной ссылке без скачивания можно настроить GitHub Pages
в **Settings → Pages → Deploy from a branch** (папка `/`), если это разрешено
тарифом и настройками репозитория. Сайт Pages обычно общедоступен даже при
приватном исходном репозитории.

## Тест в окружении Яндекс Игр

```
npx @yandex-games/sdk-dev-proxy -p .            # dev-моки платформы
npx @yandex-games/sdk-dev-proxy -p . --app-id=<ID черновика>   # prod-черновик
```

Debug-панель: `&debug-mode=16` (лоадер `IT`, `I18N is used`, SDK mocks языков).

## Публикация

1. `python tools/make_dist.py` — собирает `dist/` только из рантайм-файлов
   и пакует `game.zip` (index.html в корне архива, без пробелов и кириллицы
   в именах, ≤100 МБ). В архив НЕ попадают `tools/`, `.tmp/`, `.design-backup/`,
   dev-сиды и мёртвые ассеты — раньше всё это уезжало в черновик и раздувало
   его до ~22 МБ.
   Посмотреть состав без сборки: `python tools/make_dist.py --list`.
   Заодно вычистить неиспользуемые картинки с диска: `--prune`.
2. Загрузить архив в черновик на games.yandex.ru/console.
3. Создать лидерборд с техническим именем **`capital`** (тип «число», сортировка по убыванию).
   Топ доски видят и гости (без своего места); боты `mockLeaders()` — только
   вне платформы и как фолбэк при ошибке SDK.
4. Включить rewarded video в монетизации; interstitial не используется (все показы рекламы —
   rewarded по кнопке в логических паузах, требование 4.4/4.5 соблюдено).
5. В черновике отметить языки ru + en (оба переведены полностью).

## Что где лежит

- `index.html` — разметка всех экранов
- `css/style.css` — темы через CSS-переменные (`data-theme` на `<html>`)
- `js/yandex-sdk.js` — обертка SDK (из навыка yandex-games-dev): init, LoadingAPI.ready,
  GameplayAPI, pause/resume, сейвы с debounce, реклама, лидерборды, моки
- `js/data.js` — активы (реальные монеты), классы, новости, конфиг экономики
- `js/i18n.js` — словари RU/EN
- `js/engine.js` — детерминированный рынок: свечи от времени + возврат к средней + новости
- `js/chart.js` — свечной график на canvas (Retina, темы, линия входа в позицию)
- `js/main.js` — состояние, экраны, торговля, бонусы, рейтинг
- `js/futures.js`, `css/futures.css` — фьючерсы: вкладка «Фьючерсы» на рынке,
  шит открытия и шит управления позицией, карточка в портфеле

## Фьючерсы

Вкладка «Спот / Фьючерсы» вверху рынка. Вид фьючерсов устроен как спот: сверху
обзор рынка (капитализация, настроение, индекс страха и жадности), кошельки
спот ⇄ фьючерсы с кнопкой перевода, поиск и сортировка, список из 25 бессрочных
контрактов. Максимальное плечо зависит от размера монеты: 50× для BTC и ETH,
25× для крупных, 20× для остальных, 10× для мемкоинов.

- Отдельный фьючерсный кошелёк: деньги переводятся со спота и обратно, маржа
  и комиссия входа (0.05% от номинала) списываются с него, выплата при
  закрытии возвращается в него. Маржа изолированная: при ликвидации сгорает
  только маржа позиции.
- Экран контракта открывается шторкой, как спотовый: график с уровнями входа,
  ликвидации и TP/SL, кнопки Шорт/Лонг, внизу позиции и история по контракту.
  Ордер оформляется в отдельном шите, как покупка на споте.
- Mark-цена — живая цена движка; вход и выход — по ask/bid.
- Ликвидация: когда `маржа + PnL − фандинг` опускается до поддерживающей маржи
  (0.4% / 0.5% / 1% номинала в зависимости от плеча).
- Фандинг раз в час: ставка зависит от изменения цены за 24ч, положительная —
  лонги платят шортам.
- TP/SL задаются в процентах ROE; стоп за ценой ликвидации выбрать нельзя.
- Позицию можно закрыть частями (25–100%) и долить маржу, чтобы отодвинуть ликвидацию.
- Все позиции, кошелёк и история видны в портфеле, в карточке «Фьючерсы».
- Пока игра закрыта, при следующем запуске проверяются закрытия 5-секундных свечей
  (насколько хватает истории движка — около 10 часов): ликвидация, SL и TP
  срабатывают там, где сработали бы онлайн.
- Эквити фьючерсного счёта входит в капитал: рейтинг, классы, достижения и портфель его учитывают.
- Состояние хранится в сейве под ключом `fut`.

Спотовый экран монеты тоже открывается шторкой поверх рынка: её можно смахнуть
вниз за шапку или закрыть тапом по затемнению.

## Уведомления и анимации

- `toast(msg, cls, opts)` — уведомление сверху. `cls`: `''`, `'gold'`, `'ok'`, `'bad'`,
  `'toast-ach'`. `opts`: `img` (картинка вместо иконки, например логотип монеты),
  `sub` (вторая строка), `ms` (время жизни), `action: { label, fn }` (кнопка),
  `onClose`. Текст вида «заголовок · значение» сам делится на две строки.
  Одинаковые сообщения подряд склеиваются со счётчиком ×N, на экране не больше
  трёх. Уведомление закрывается тапом или смахиванием.
- Сделка: после подтверждения кнопка на полсекунды показывает итог
  («✓ Куплено …»), затем шторка закрывается и монеты летят в иконку монеты
  в шапке (`tradeFinish`, `FX.fly`).
- Колесо: рамка с лампочками, пауза с подсветкой выигравшего сектора перед
  окном приза, крутить можно и тапом по центру. Окна достижений ждут, пока
  колесо не остановится и окно приза не закроют.
- Нижние шторки закрываются смахиванием вниз за шапку.

При изменении JS/CSS поднимайте номер `?v=` у всех подключений в `index.html`
разом, иначе браузер может взять старый файл из кеша.

## Соответствие требованиям модерации (кратко)

- SDK по документации, `LoadingAPI.ready()` после готовности UI, разметка GameplayAPI (1.19)
- Гостевой режим с сохранением прогресса, авторизация только по кнопке с объяснением выгоды (1.2)
- Сейвы сразу после каждой сделки/бонуса через `player.setData` (1.9)
- Вся реклама через SDK, rewarded по явной кнопке, награда — бонус (4.1, 4.5)
- Виртуальные деньги, дисклеймер «не инвестиционная рекомендация», никакого вывода (3.7)
- Язык из `ysdk.environment.i18n.lang` на старте, полный перевод ru/en (2.10, 2.14)
- Прогресс: капитал → 10 классов + цель $1M + лидерборд (критерии механик 2.4)
- Без внешних ссылок, без реальных брендов, новости заданы заранее — без интерактивного ИИ (1.23, 8.4)

## Перед релизом

- Придумать уникальное название (сейчас рабочее «TradeUp») и заменить `<title>`/тексты.
- Иконка 512×512 и обложка — НЕ скриншоты; скриншоты — реальный геймплей ≥70% кадра.
- Заполнить «Как играть» (управление описано в модалке — продублировать в поле черновика).
